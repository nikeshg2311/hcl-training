\# Day 2 - Language Fundamentals



\## Objective



Learn Java language fundamentals and Git fundamentals through a

Monthly Usage Analyzer program.



\## Topics Covered



\- Primitive data types

\- Arrays

\- Variables and constants

\- Operators

\- Type casting

\- Widening conversion

\- Narrowing conversion

\- Integer overflow

\- Floating-point precision

\- 2-D arrays

\- Git basics



\## Monthly Usage Analyzer



The program stores usage data for 12 months using an integer array.



It calculates:



\- Total usage

\- Average usage

\- Minimum usage

\- Maximum usage
