# Day 11 — AI Integration (Core Java)

## Objective
Use an AI coding assistant to generate, review, improve, and test Java code.

## Folder Structure
```text
day-11-ai-integration/
├── README.md
├── AI-USAGE.md
├── evidence/
└── src/
    └── main/
        └── java/
            └── app/
                ├── Student.java
                ├── StudentService.java
                └── StudentServiceApp.java
```

## Run the Program
From this directory, compile the source files:

```powershell
javac -d out src\main\java\app\Student.java src\main\java\app\StudentService.java src\main\java\app\StudentServiceApp.java
```

Run the demo:

```powershell
java -cp out app.StudentServiceApp
```

## Evidence
Store screenshots of the AI prompts, generated code, code review, and successful program output in the `evidence` folder.
